# 2026-11-23

## 사용자에게 보이는 변화
- 나인그리드 첫 정식 버전 v1.0.0을 냄. 지금까지 만든 기능을 묶은 버전으로, 화면이 따로 바뀐 것은 없음 (#40)
- 키보드와 스크린리더로 쓰기 편해짐 (#33, 이슈 #9)
  - 맨 앞의 "보드로 바로 가기"를 누르면 바로 보드로 이동함
  - Tab은 블록마다 한 번씩 멈추고, 블록 안에서는 방향키로 칸을 옮겨 다님. 글을 쓰는 중에는 커서가 글의 맨 앞이나 맨 끝에 있을 때만 다음 칸으로 넘어감
  - 실천 칸에서 Ctrl+Enter(Mac은 ⌘Enter)를 누르면 완료 체크가 바뀌고, 바뀐 달성률을 읽어 줌
  - 칸을 "3번 블록, 실천 5, 완료"처럼 읽어 줌
  - "확대"를 누르면 그 블록의 칸으로 바로 이동하고, 창을 닫으면 창을 열었던 버튼으로 돌아감
  - 회색 글자가 조금 진해져 더 잘 보이고, 움직임 줄이기를 켠 기기에서는 화면 전환 효과가 꺼짐
- 보드를 여러 개 만들어 쓸 수 있게 됨 (#34, 이슈 #10)
  - 보드 이름 버튼을 누르면 "내 보드" 창이 열리고, 보드 전환, "새 보드", 이름 바꾸기, "복제", "이 보드만 백업", "삭제"를 할 수 있음. 보드는 최대 20개
  - 다시 열면 마지막에 보던 보드가 열림. 실행 취소 기록은 보드마다 따로 남음
  - 지금까지 쓰던 보드는 첫 번째 보드로 자동으로 옮겨짐
  - "예시 보드"는 지금 보드에 내용이 있으면 덮어쓰지 않고 새 보드로 추가됨
  - 상단 백업 버튼 이름이 "JSON 백업 다운로드 (전체 보드)"로 바뀌고, 모든 보드를 한 파일로 받음. 보드 하나만 백업한 파일이나 이전 버전 백업 파일을 복원하면 새 보드로 추가됨
- 영역마다 얼마나 했는지 보이고, 날짜별 달성률이 기록됨 (#35, 이슈 #11)
  - 바깥 8개 블록 제목 줄에 진행 막대와 "완료/작성" 개수가 보이고, 아직 쓴 실천이 없으면 "작성 전"으로 표시됨
  - 보드 아래 "영역별 달성률" 카드에서 8개 영역을 한눈에 보고, 영역 이름을 누르면 그 영역의 포커스 모드로 감
  - "진척 기록" 카드에 날짜별 달성률 그래프가 나옴("최근 4주" / "전체"). 하루에 한 번, 그날의 마지막 값으로 기록되고 칸의 글은 기록하지 않음
- 실천 칸을 다른 칸으로 옮길 수 있게 됨 (#36, 이슈 #13)
  - 실천 칸 아래쪽 손잡이(⠿)를 끌어 다른 실천 칸에 놓으면 옮겨짐. 빈 칸이면 그 자리로 옮기고, 내용이 있는 칸이면 두 칸의 자리가 바뀜. 글과 완료 체크가 함께 옮겨짐
  - 끄는 동안 놓을 자리에 "여기로 이동" 또는 "자리 바꾸기"가 보이고, Esc로 취소할 수 있음
  - 손잡이를 누르기만 하거나 실천 칸에서 Alt+M(Mac은 ⌥M)을 누르면 "다른 칸으로 이동" 창에서 블록과 자리를 골라 옮길 수 있음
  - 옮긴 것도 "실행 취소"로 되돌릴 수 있음
  - 휴대폰·태블릿에서는 손잡이를 끌 때만 옮겨지고, 칸의 다른 곳을 끌면 그대로 스크롤됨
- 배포된 사이트에 방문 통계를 붙임. 쿠키를 쓰지 않고 보드 내용은 보내지 않음 (#37, 이슈 #14)
