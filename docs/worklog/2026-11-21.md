# 2026-11-21

## 사용자에게 보이는 변화
- 나인그리드를 앱처럼 설치할 수 있게 됨 (#23, 이슈 #6)
  - Chrome·Edge·Android에서 설치할 수 있는 상태가 되면 상단에 "앱으로 설치" 버튼이 나타남
  - iPhone·iPad는 Safari의 공유 버튼 → "홈 화면에 추가"로 설치함. iOS는 설치 버튼을 지원하지 않아 버튼은 나타나지 않음
- 한 번 연 뒤에는 인터넷이 끊겨도 앱을 열고 보드를 편집할 수 있음. 처음 준비가 끝나면 "이제 인터넷 연결 없이도 NineGrid를 열 수 있습니다." 알림이 한 번 뜸 (#23)
- 새 버전이 배포되면 상단에 안내가 뜨고, "새로고침"을 눌러야 적용됨. 입력하던 중에 화면이 저절로 새로고침되지 않으며, 보드 내용은 그대로 남음 (#23)
  - "나중에"를 누르면 안내를 닫을 수 있음
  - 새로고침하면 실행 취소 기록은 사라짐
- 보드를 종이로 뽑거나 PDF로 저장할 수 있게 됨. 상단의 "인쇄 / PDF 저장" 버튼을 누르고 인쇄할 내용을 고른 뒤 "인쇄하기"를 누름 (#24, 이슈 #12)
  - "현재 보드": 작성한 내용과 완료 체크(☑/☐), 전체 달성률, 인쇄일을 함께 인쇄함
  - "빈 양식": 칸과 체크 상자만 인쇄해 손으로 채워 쓸 수 있음
  - A4 가로 한 장에 전체 보드가 들어감. 다크 테마나 포커스 모드에서도 항상 흰 바탕의 전체 보드가 인쇄됨
  - 흑백으로 인쇄해도 블록이 굵은 테두리로 구분되고, 긴 글은 칸에 맞춰 글자가 작아져 잘리지 않음
  - 인쇄 창에서 대상을 "PDF로 저장"으로 고르면 PDF 파일이 됨

## 내부 작업
- `vite-plugin-pwa`로 manifest와 Service Worker 추가. 앱 셸(JS·CSS·HTML·SVG·아이콘)만 미리 저장하고 og.png는 제외. 배포마다 파일 해시가 바뀌어 오래된 캐시는 정리됨 (#23)
- Service Worker 등록, 1시간마다 새 버전 확인, 설치 버튼 처리를 `src/pwa.ts` 훅으로 분리 (#23)
- PWA 아이콘(192/512, maskable, apple-touch-icon)을 `favicon.svg`로 생성. 다시 만들 때는 `npm run generate-pwa-assets` (`pwa-assets.config.ts`) (#23)
- 인쇄는 화면의 입력창 대신 인쇄 전용 보드를 따로 그리는 방식으로 구현. 칸 데이터 생성(칸 종류, 체크 표시, 글자 크기 단계)을 `src/print.ts` 순수 함수로 분리하고 테스트 10개 추가 (#24)
- 라이브러리 없이 CSS `@media print`와 `window.print()`만 사용. 인쇄용 색 변수(`--print-*`)를 라이트/다크 양쪽에 추가 (#24)
- 헤드리스 Chrome으로 4개 언어·빈 양식 PDF를 만들어 모두 1장에 나오는지 확인하고, 모든 칸을 70자로 채운 경우에도 넘치지 않도록 글자 크기 기준을 조정함 (#24)
- 새 문구 4개 언어 추가(PWA 5개, 인쇄 11개), README에 설치 방법·저장소 차이·인쇄 기능 안내 추가 (#23, #24)
- 저장 데이터 구조(`ninegrid-board-v1`)는 바뀌지 않아 마이그레이션 없음

## 확인 필요
- 배포 후 `/sw.js`와 `/manifest.webmanifest`가 제대로 제공되는지 (Cloudflare 배포 설정이 저장소에 없어 로컬 빌드로만 확인함)
- Chrome·Edge에서 "앱으로 설치" 버튼이 실제로 나타나는지, Android·iOS 실기기에서 홈 화면 설치와 비행기 모드 실행이 되는지
- iOS 홈 화면 앱은 브라우저와 저장 공간이 따로일 수 있어, 브라우저에서 쓰던 보드가 앱에서 보이지 않을 수 있음 (README에 백업→복원 안내)
- "인쇄하기"를 눌렀을 때 인쇄 창이 열리는 마지막 단계와 Windows(Chrome/Edge)·Android·iPadOS 인쇄 미리보기
- 오늘 추가한 PWA 문구(한국어)는 "~습니다", 인쇄 문구는 기존 화면처럼 "~해요" 말투라 섞여 있음
- 이슈 #6의 완료 조건 "Lighthouse PWA 항목 통과"는 최신 Lighthouse에 PWA 항목이 없어 설치 조건을 직접 맞추는 것으로 대신함
